# Centra Sculpt — UI follow-up

1. **What changed:** Renamed the product in the browser title, header/mark, footer, native-file error messages and GLB download names. Refreshed the studio shell, panel styling, header/footer layout and contrasting circular viewport controls. Sculpt tools exposes Brush / Boolean; Boolean opens procedural Add/Subtract shape stamping, as clarified by the user. The layer wheel exposes Move / Rotate / Scale. Sidebar controls remain available.
2. **Technical decisions:** New `src/viewport-tools.ts` is a scene-independent DOM overlay. It delegates to existing command/gizmo handlers and synchronizes mode state. Shape Library now exposes `setOpen`; Brush/B hides/collapses it, while layer-tool selection also clears the ghost before enabling its gizmo. Only one wheel opens at once. Menus support pointer/touch, keyboard focus/arrows/Home/End, Enter/Space and Escape. Locked/hidden layers disable layer transforms; busy/modal operations disable both wheels. Menu pointer events do not reach the canvas. Storage signature and `.form` extension remain compatible.
3. **Build/tests:** `npm run build` passed. `npm test`: **168 passed, zero failures**. The invalid-file test now expects the new app name; validation coverage is unchanged. Browser checks verified both menus, shape-panel activation, Rotate/Scale/Move, Brush/B restoration, keyboard selection and locked-layer guards. Repeated mode changes left history at 0/0 and the original sphere at 31,536 triangles. An existing two-layer `.form` opened with its hidden 64³ Base, active 128³ stamped geometry (131,596 triangles), flags, IDs and colours retained.
4. **Performance:** No SDF/meshing/history algorithm changes or new sculpting benchmark. Wheel state synchronization skips unchanged states. Build output ~692 kB JS minified; existing bundle-size advisory remains. DOM/GPU timing was not benchmarked.
5. **Limits:** Phone layout was verified with a 390×844 browser viewport, not physical touch hardware. The 224px open menu fit within the viewport, with document width equal to 390px (no horizontal overflow). Original viewport sizing was restored. No new camera gestures, deformation tools or ghost gizmos were introduced. `.form` remains the native extension.
6. **Next phase:** Reuse the tool-wheel command boundary for future interaction controls; keep layer Boolean Preview separate from shape stamping. A future ghost gizmo should manipulate the preview model with explicit input ownership.
