Physical verification is pending. Automated build and 250 tests pass. Launch using the existing secure-origin workflow in QUEST_WEBXR.md / VR_POLISH.md.

1. Enter VR. Confirm neutral grey, correctly handed realistic Quest Touch Plus models and normal fit. Tool grip alone must do nothing. Support grip must retain the previous direct movement and wrist rotation.
2. Hold Support, move/rotate, then hold Tool with hands separated by more than 3 cm. Joining must not jump. Move both hands together: whole workspace follows midpoint translation. Rotate the connecting line: workspace rotates around the captured midpoint. Spread/close hands: uniform scaling; repeat identical poses to check drift. Dual wrist roll alone has no effect; vector rotation is the defined policy.
3. Release Tool while holding Support. No jump; Support wrist movement continues. Repeat releasing Support first: Tool continues from its current pose until released. Release both: workspace stays put. Rejoin repeatedly at varied poses and scales.
4. Bring hands within 3 cm: workspace freezes, then recaptures anchors when separated without a recovery jump. Scale is bounded to .001–100 local workspace scale (including an out-of-range entry fit); verify practical limits comfortably rather than reaching unsafe physical distances.
5. Repeat steps 1–3 after swapping dominant hand. Physical handedness must stay correct regardless of connection order. Test simultaneous grips and Tool-first then Support.
6. While holding both grips, cover a controller / lose tracking, disconnect/reconnect it, open the system menu, blur/restore the session, and change handedness from the mirror. Workspace must freeze; release/repress is required before restarting. No stale model or recovery snap. Repeat during one-hand continuation.
7. Reset using the mirror during a grab; reset must cancel/rearm and restore original entry fit. Release, then test the headset Reset control. Simple/Minimal/Realistic, hints, diagnostic details and performance remain available; active grabs must suppress debug ray actions. Both participants should show active feedback.
8. Use independent layers and Boolean preview separately. Confirm every visible sculpt moves together; no layer metadata, undo count or source triangle count changes. Save/export before and after navigation outside XR: project-space coordinates must match. Exit restores desktop camera/background/editing; re-entry fits afresh without duplicate controller assets.
9. Enable performance panel and record runtime/browser, layers/resolution, style, render calls/triangles and interval statistics while idle/single/dual. Callback/JS timings are not GPU or motion-to-photon measurements. Report discontinuities, discomfort or frame spikes; no physical performance claim has been made.
